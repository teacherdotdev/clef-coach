# 3. Band activities offer seven concert keys

Date: 2026-10-25

## Status

Accepted

## Context

String activities offer seven keys, up to three sharps or three flats, chosen
for beginning string players. Band activities are set in concert pitch
(ADR 0001), and transposing moves each concert key to a different written key
per instrument — so the written keys the app must draw and finger are wider than
the concert keys a teacher picks.

## Decision

A band activity is in one of seven concert keys: B♭, E♭, F, A♭, C, D♭ and G —
the keys school band books use. Across flute, the B♭ instruments, the E♭
instruments and F horn these are written in every major key from five flats (D♭)
to four sharps (E), so the app gains A♭, D♭ and E major as written keys.

## Consequences

- Key-signature drawing must place a fourth and fifth flat and a fourth sharp in
  every clef.
- The string activities could use the new keys too, but nothing requires it.
- More remote keys (G♭, B, etc.) stay out until a teacher asks.
